- Deterministic verification before inference; no builds during inference or destructive library rebuilds during host verification. Long commands detached. Archive-first/generated-only cleanup preserves domain/authority and all failed evidence.

## Implementation now present

`FragmentComposition.kt` accepts `{title,fragments,commands,display}` with independently namespaced input/read/result/comparison/choice/allocation/alternatives/quotes. `MaintainedFormula.kt` parses pure expressions, preflights bindings and lowers to the retained typed emitter. Contracts own actual nested semantic configs, quotas, roles and arguments. Explicit ports carry types and optional presence; invalid identifiers, duplicates, missing refs, cycles and omitted visible fragments reject.

Commands name resources/outcomes; embedding derives dependency execution and downstream local initialization, only when all transitive resource prerequisites are in the command. Shared async owners reject explicitly. Per-command epochs/pending/error and current-state completion merges preserve independent resources. Normal forward clock ticks do not cancel quotes; trust loss does. Quote expiry starts conservatively at each actual reply. Allocation publishes current presence separately from feasibility. Exclusive roles consume distinct physical units; additive quotas may overlap. One-level bundles share direct/component stock; nested/unknown components reject. Combinatorial growth remains unproven.

The OHOS adaptation uses independent bundled fragments/namespacing/composition and a pure parser—not its selector calls, implicit first-other port matching, numeric coercions or two-round repair limit. Legacy whole-behavior/graph fixtures remain regression mechanisms, not shipping native authoring. SelectionComposition remains isolated and unpromoted.
