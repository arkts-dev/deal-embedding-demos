## Delivered behavior

The model selects a maintained comparison, provider schedule, constrained editable allocation or authoritative quoted-alternatives fragment. It supplies requirements and disclosed bindings, not state/action/view graphs. Maintained code owns those graphs, provider sequencing, allocation, component matching, invalidation and freshness. The four workflows require no custom source. Provider records, stock, eligibility, whole-basket prices and deposits remain authoritative.

Canonical DEAL/Deal UI materializes once. Compilation failure or later change uses the existing digest/revision-bound exact-edit path, never reassembly. Explicit typed custom sections and full-source fallback remain separately charged slow paths. No extra selector/verifier request was introduced.

Fixed stale pending completions after input invalidation, success retained through failed refresh, and quote lifetimes starting at combined completion. Each quote now records its own conservative second-resolution receipt expiry. Lifecycle/backward-clock changes fence pending completions. Equipment enumerates stock-qualified component-matching packages and separate baskets and requests authoritative whole-basket quotes, including alternatives after unavailable replies. Allocation uses memoization, normalized quota state and provable quota-feasibility pruning; operational failures are not translated into infeasibility.

## Verification and limits

Coverage includes opaque IDs, edits during outstanding reads, failed refresh, infeasible 32-row allocation, late windows, stock-qualified alternatives, unavailable quote alternatives, delayed sequential replies spanning TTL, backward clock and restoration. Exact source-repair, source-agent, public protocol, guidance, API mirrors, transport, metrics, collector and artifact-boundary host checks pass. Builds, installed-byte checks and independent commits are retained; no push.

The authorized four-workflow contract now has implementation, deterministic regression evidence and a measured live four-task pass. This does not establish arbitrary-workflow coverage, repeated-cohort reliability or visual approval. The preceding discovery failure remains a real observed reliability limit, not an external blocker or a successful delivery.
