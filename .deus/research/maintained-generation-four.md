## Implementation

Replaced the raw-body compact composer with a closed typed graph emitter. Maintained operations cover arithmetic, formatting, projection/filter/join/aggregation, immutable keyed edits, constrained allocation, component-ID matching, basket serialization and ordered capability workflows. Capability records remain provider-owned. Initial construction emits canonical DEAL/Deal UI once; all later repair uses revision-bound atomic exact edits. Custom typed sections and full-source fallback remain explicit, distinct routes. No selector/verifier model call was added.

Added minute-of-day TimeField, direct integer entry and resumed-lifecycle SessionClock. Generated DEAL owns freshness policy; native lifecycle signals invalidate trust and fence stale completions. Pizza now discloses numeric diameter and rejects malformed deadlines rather than substituting a time.

Generation bridge producers are evaluated once and drained losslessly in bounded JSON chunks. Active repair history retains the latest native exchange plus current canonical pair/diagnostic, not every historical source copy. Complete prior evidence remains observable.

Host gateway/transport, source-agent, source-repair, protocol, guidance, cohort-collector and API-mirror checks pass. Its accepted route was maintained-only with no custom characters, full-source fallback or canonical source edits, but 14 rejected plan submissions preceded acceptance. Initial errors included undeclared derived fields, invalid component names and nonliteral view computations.

Departure repeatedly put numeric `travelMinutes` in `controls.invalidate`, which only sets boolean validity fields false. Rejection said only `Expected boolean, got number`, and subsequent submissions repeated the error. This is a real composition/guidance/diagnostic failure despite passing supplied-plan execution. There is no evidence of a DEAL compiler defect. The operator stopped the process after 125 completed departure replies without a frame rather than allowing unbounded spend. The resulting process-crashed marker was operator-induced, not a spontaneous runtime crash or semantic failure. This interruption is **not** a completed four-task aggregate and was not retried or retimed.

Discovery usage is excluded from these source totals. No completed departure summary exists, so its total elapsed/check time is not invented.

## Post-cohort correction and remaining work

After stopping, validation was changed to name the control and offending nonboolean invalidation field and explain the boolean-flag contract; the schema and guidance now state it explicitly. Host four-plan runtime tests and seven gateway tests pass after this diagnostic-only correction. This correction was **not** part of measured bytes and has no demonstrated live benefit or installed-byte claim.

The product objective remains unmet: supplied deterministic plans work, but automatic typed-plan composition incurred runaway rejection and no full fresh cohort completed. Ordinary discover→generate→edit→reopen visual acceptance remains unverified. No second live run was used to replace the failed evidence.
