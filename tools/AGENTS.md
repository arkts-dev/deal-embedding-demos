# Tooling

Preserve Android dependency service descriptors/root properties alongside D8 output; never duplicate host Guava/Kotlin runtimes. Fingerprint resolved dependencies, all packaging inputs and authoritative library ui/. Library builds have no consuming-app inputs. Policy builders compile trusted DEAL/package source without selecting answers. Host checks execute v1.5 and production JS sessions with exact packaged inputs, revisions/hashes and settled restoration; mock external boundaries only. No historical compiler lane.

Run deterministic checks before opt-in inference. Verifiers consume embedding-library/embedding-consumer: never overlap them with destructive rebuilds. No build/inference overlap. Keep private source, logs, screenshots and receipts in ignored build/.

Behavior fixtures supply requirements/disclosed bindings only, never production guidance. Exercise maintained state/actions/views through real emitter/compiler/session, including failed refresh, edits while pending, sequential replies spanning TTL, stock-qualified alternatives and whole-basket authority. Formula tests cover grammar/injection/preflight/nesting/precedence and real arithmetic emission, not another evaluator. Legacy formula/selection adapters are consuming fixtures only. Replay captured plans read-only; preserve rejection without correcting inputs. Supplied-plan runtime passes are not live authoring or delivery. Route/custom/operation accounting survives artifact eviction.

Credentials/provider parameters stay in the loopback gateway. Apps provide endpoint/backend configuration to embedding's connection client, never app HTTP implementations. APK DEAL_GENERATION_BACKEND selects cerebras (default) or cortex; preserve selection on rebuild and verify installed selection/actual requests, not gateway defaults. Discovery selects independently through DEAL_DISCOVERY_BACKEND=nano/deepseek-flash with separate cloud opt-in. No silent backend switch. Gateway alone reads keys; never package/log them.

Purges require explicit authorization: archive first, preserve domain/authority/original measurements and verify generated-only scope before inference. Never clear package data. Enriched setup adds absent-only isolated records; do not overwrite records/source/state/failures/authority. Keep fixture provenance in tooling/Inspect, not task canvases. Compare private archives for preservation.

Aggregate unified metrics using latest request summaries and unique repair IDs. Missing usage remains unknown; report denominators/revisions and reasoning separately from completion totals. Receipt timing is not model compute; patch locality is not semantic preservation. Keep deterministic, device, live-model and visual results distinct. Screenshots/tree checks do not establish design quality; leave visual review pending when unperformed.

Use provider-documented independent initial/repair reasoning and completion settings. Source reasoning stays enabled; retain no disabled-reasoning lane. Streaming collects receipt counters, never executes partial source or retains hidden reasoning. Preserve invariant system prefixes without duplicate bases and verify actual cache counters.

Initial tools are strict native submit_compact/submit_custom/source_fallback. Load embedding-owned schemas; do not duplicate compact contracts. Maintained submission names fragments, nested semantic configs/formulas, command targets and bindings. Custom sections measure reason/volume; full-source fallback is explicit. Distinguish coverage from catalogue origin and retain every fallback/repair transition.

Core owns phase, workspace, revision binding, tool execution and admission. Gateway only transports messages. No parallel compact calls; write_file only after fallback; read/edit/check only after materialization. Never retain raw framing, executable pair/patch envelopes or fallback extraction. Internal/API/catalogue JSON remains valid. Assemble complete indexed streamed tool arguments, preserving call/result IDs. Enable multi-call only from core initialWrites metadata, not guessed pair absence. Require nullable read bounds; core validates inclusive literal-numbered reads without size ceilings.

Repairs are unique/disjoint revision-bound exact patches, never rewrites/strategy fallbacks. Preserve the valid base and feedback on rejection. Recover within the same request, recording retries; no manual retry taps disguised as e2e recovery. Trusted runtime tests may feed actual failures to exact repair. Live checks require explicit opt-in, retain failures and never inject answers. Optimize usefulness, locality, latency and preservation—not zero repairs. Hidden reasoning never enters reports.

Shell device checks enter common Settings/Inspect in all apps, separate proposal confirmation, and cancel reset without deleting user experiences. Destructive reset regressions use isolated contexts unless explicitly authorized. Screens show tasks/controls/status/consent; Inspect owns diagnostics. Test real ordinary journeys separately from native fixtures, restoration and fresh inference.
