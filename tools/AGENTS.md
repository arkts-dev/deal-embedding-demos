# Tooling

Keep library builds independent of consuming apps. App policy builders compile trusted DEAL and package authored source without selecting semantic answers. Credentials stay in the existing loopback gateway, never generated assets or receipts. Host APKs select cortex/cerebras through DEAL_GENERATION_BACKEND at build time; transport forwards that explicit selection, never silently switches providers. Keep provider parameterization in the gateway, not app domain code or embedding's portable runtime.

Distinguish deterministic compiled-policy checks, real-device interaction checks and live-model evaluation. Live checks require explicit opt-in, retain failed attempts, never inject an expected answer and never silently retry inference. Device fixtures may replace labelled demo records only. Store private screenshots/logs under ignored build output, not tracked documentation.
