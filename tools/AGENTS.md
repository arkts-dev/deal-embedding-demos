# Tooling

Manual Android packaging must preserve inference dependency service descriptors and root properties alongside D8 output, without adding a second copy of the host's Guava or Kotlin runtime. Fingerprint resolved dependencies and packaging inputs, including the library's authoritative ui/ directory; do not hide availability or operational failures behind discovery abstention. Toolkit host checks must execute the current DEAL 1.3 compiler and production JS loader/session, mock only external boundaries, assert exact packaged inputs and record revisions plus hashes. Do not reintroduce historical compiler/pack compatibility lanes; test current source and settled-state restoration. Keep private saved-source fixtures and receipts under ignored build output.

Keep library builds independent of consuming apps. App policy builders compile trusted DEAL and package authored source without selecting semantic answers. Credentials stay in the existing loopback gateway, never generated assets or receipts. Host APKs select cortex/cerebras through DEAL_GENERATION_BACKEND at build time; Cerebras is the default. Preserve the requested backend when rebuilding and inspect the installed selection plus actual request evidence, not just the gateway default. Select discovery independently with DEAL_DISCOVERY_BACKEND=nano/deepseek-flash; retain local inference and keep cloud opt-in separate. The external gateway alone reads DEXTER_DEEPSEEK_API_KEY. Benchmark purges require explicit authorization, archive first, preserve domain/authority and old measurement directories, and verify zero saved source/drafts/links before any inference. Generated host bootstrap supplies endpoint/backend configuration to embedding's library-owned gateway client; do not compile an app-owned connection implementation. The client forwards that explicit selection, never silently switches providers. Keep provider parameterization and credentials in the external gateway, not app domain code or embedding's portable runtime.

Distinguish deterministic compiled-policy checks, real-device interaction checks, live-model evaluation and visual acceptance. Presentation capture/check tooling must explicitly leave visual review pending; screenshots and UI-tree checks alone do not establish design quality. Capture task, suggestion, pending, empty, failure and Inspect states without silently injecting expected model output. Keep initial/repair reasoning effort and completion limits independently configurable in the external gateway, using provider-documented values only. Stream measurement may collect receipt timestamps/counters but never execute partial source or retain/print hidden reasoning. Preserve invariant system prefixes, exclude duplicate patch bases, and verify actual cache counters. Source reasoning must stay enabled; remove disabled-reasoning experiments rather than retaining a dormant option. Repairs are only revision-bound exact patches, never full rewrites or strategy-selected fallbacks. Treat bounded repairs as normal for complex cases; optimize locality, latency and behavior preservation, not a zero-repair target. Report provider reasoning-token counts separately from completion totals and elapsed time; missing counts are unknown, not zero, and hidden reasoning text must never appear in reports. Live checks require explicit opt-in, retain failed attempts, never inject an expected answer and never silently retry inference. Device fixtures may replace labelled demo records only. Enriched-journey setup adds absent-only isolated review records with realistic task names; never overwrite existing records, saved source/state, failed evidence or authority. Keep fixture provenance in tooling/Inspect rather than acceptance instructions on the task canvas. Compare private before/after archives to establish preservation. Shell UI checks must enter the same Settings/Inspect classes in all apps, keep proposal confirmation separate, and test reset cancellation without deleting existing user experiences. Destructive reset behavior belongs in isolated native regressions unless explicitly approved for device data. Store private screenshots/logs under ignored build output, not tracked documentation.
