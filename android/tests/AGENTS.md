# Android tests

Discovery boundary tests use injected inference and real protocol admission; live Nano checks require explicit opt-in and retain semantic failures separately from parser/availability errors. Calendar confirmation checks use a controlled dedicated-demo event and delete it afterward. Keep live expectations out of model input. Gateway fixtures use local HTTP servers and the compiled generate path; verify backend/path forwarding, checked interaction, cancellation, bounded errors and capture policy without live model calls.

Inspection regressions must read events/artifacts through ApplicationProtocol and use canonical experience/session identifiers; test transitive handoffs, missing/incomplete evidence, capture-off/nonretroactive snapshots and publication separately from production. Keep native-storage corruption tests confined to explicit observation failure checks. Exercise capture across simultaneously active protocol/Inspect instances, including reader closure and nonretroactivity. Consent-migration tests use isolated preferences and preserve explicit OFF. Failure-recovery tests inject failures rather than using live inference and distinguish explicit retry from lifecycle resume.

Rental read-validation tests use isolated preferences, exercise the real canonical native handlers and preserve installed sharing/domain records. Assert rejected malformed baskets/periods, exact totals and component-stock consumption, not just schema-valid replies. Exercise source-bound draft retention across actual process/XML reloads, cold protocol reconstruction and concurrent Inspect-style readers, not only close/run on one instance. Prefer short regressions through real compiled artifacts and framework adapters. Keep deterministic model fixtures distinct from live inference evidence. Use controlled test/demo records only, preserve personal records and cleanup issued resources. Do not add source-pattern assertions as substitutes for functional session checks. Guidance and toolkit regressions consume the exact library-packaged ui/ source pairs, with fixture-only host/sample and explicit empty/pending/success/failure/retry; never expose that capability to ordinary apps. Toolkit gallery screens use the real compiler/runtime and ExperienceSurface with realistic task content; engineering facts belong behind Inspect. Verify explicit comparison status, bounds, payloads, typed dynamic children and cold retention independently from device visuals and model adherence.
