# Calendar

Keep ordinary UI task-first and Material: classify content, actions, status and consent; move diagnostics, model names, note transcripts and implementation explanations to common Inspect. Use shared tokens, flat hierarchy, concise labels and native controls; no decorative heroes/backgrounds. Reference: https://github.com/nexu-io/open-design/blob/main/design-systems/material/DESIGN.md. Toolbar contains navigation, readable task title, Inspect and overflow; Settings belongs in overflow.

Calendar date → event → automatic discovery → Open → checked tool is the ordinary journey. Keep week/day agenda; event taps open PreparationActivity, event details remain a menu action. Never restore a separate authored assistance route, Extensions wrapper, access popup, discovery policy or backend-named generation consent. Shared Settings exclusively owns discovery/generation disclosure, sharing, remote/selected-event grants and confirmed assistance reset; honor OFF without resurrecting obsolete preferences. Open accepts and generates; native write confirmation stays separate.

PreparationActivity supplies authorized immutable event facts, persistence and authority hooks to shared AssistedTask. Framework DEAL/Deal UI owns suggestion/Open/Dismiss, discovery, generation and activation; embedding owns compilation/execution/rendering. Bind discovery once to the protocol; supply facts, never a catalogue or interpreted note plan. Invalidate on foreground/provider changes; fence provider actions to captured event revision. Preserve exact facts, freshness, accepted evidence and dismissal; no scenario branches or obligatory suggestions.

Use GenerationGatewayConfig endpoint/backend values, not app ModelClient implementations, pumps or renderer wiring. Library owns cancellation, telemetry, inspection scope and capture/events/artifact. Inspect uses common Activity/Dialogue/Source with experience/request scope; never duplicate trace joins, handoff interpretation or snapshot files. Keep app decisions in the app-record adapter, not duplicated inference outcomes; preserve them on reset. Retain source/drafts input-bound through framework storage and common Inspect/reset.

Calendar Provider remains authoritative. Preserve grants, consent, reminders and revision checks before writes. Isolate dedicated demo records from personal edits. Keep arithmetic/interaction in checked experiences.

Visual acceptance requires actual phone screenshots of suggestion/pending/populated/empty/failure states, reviewed for hierarchy, density, primary action and controls/results proximity. Verify Inspect retains displaced details. Builds/tree assertions are not visual review; inability to see images leaves acceptance open. Never filter checked trees or rewrite accepted source to repair presentation.
