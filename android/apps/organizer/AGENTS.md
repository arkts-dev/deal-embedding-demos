# Organizer assistance

Follow the frozen contract in `.deus/design/organizer-assistance.md`. Initiate assistance through an event requirement, never a workspace or generation-mode launcher. Use task language on ordinary screens; Inspect is the single entrance for engineering taxonomy, source, provenance and unified activity.

Use shared AssistanceDesign/Material presentation rules. Show actionable connection/timeout/rejection explanations rather than exception names or source-attempt counts on ordinary screens; keep exact gateway codes and causes in Inspect. Disable conflicting actions and edits while their real operation is pending; show truthful progress and restore controls on completion/failure/cancellation. Keep Inspect and appropriate cancellation available. No inert buttons or simulated operational results.

Publish a fresh ShowState identity for plan edits; do not mutate the previously rendered plan object. Use `ApplicationProtocol` through the compiled DEAL consumer; do not call native Embedding mechanisms directly. Use the framework `ExperienceSurface` for accepted experiences; app code chooses activation, placement, retention and explicit closure, not run/next/dispatch/published or renderer event wiring. Navigation/review may detach rendering while retaining the owner; deletion and activity destruction explicitly close it. Destruction attempts all owners and the protocol independently before reporting cleanup errors. Embedding drives progress; never add app polling, transport pumps or scheduler timers. Preserve accepted source and the previous requirement link on failed replacement. Requirement identity includes exact quantity/specification/period; never infer links or authorship from saved source/title. Route decisions and equipment eligibility/source synthesis remain in app-linked DEAL policy. Author local capabilities with the shared WireType/Parameter vocabulary; convert only at the native transport boundary. Inspect uses framework bounded paging/correlation helpers rather than storage files, preferences or duplicated protocol traversal. Keep domain labels/date formatting app-owned; use framework display-only tree transforms. Present typed protocol failure codes, not native generator/gateway exception classes.

Bind local review records to the native invoking workspace, not a global latest-record guess. Durable earlier preparation must not expose stale review on cold mount; restore review only for a still-current live session or a new staging reference. Requirement-linked shell navigation must not duplicate retained content's task heading. Dialogue lists newest exchanges first while retaining request → reply → observed check feedback order inside each exchange. Correlate replies by trace/span/parent; never fabricate evicted requests or terminal events. Limit whole exchanges after grouping, not unrelated provider/action events. Activity remains newest event first. Preparation never establishes booking or coverage. Preserve exact provider arguments, consent and machine timestamps; shorten presentation only. Keep raw diagnostics in Inspect without hiding actionable operational errors.

Configure standard generation with embedding's GenerationGatewayConfig; apps supply endpoint/backend values, not ModelClient connection implementations. Keep request/response handling, cancellation and provider telemetry library-owned.

Clearly separate test-only authored source/frozen UI states from live model evidence. Extend renderer widgets only for demonstrated task needs, with typed contracts and actual compiler/sandbox/device checks.
